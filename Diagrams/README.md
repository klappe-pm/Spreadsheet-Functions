# Function Relationship Diagrams

Mermaid diagrams of how Excel and Google Sheets functions relate: which functions are commonly used together and which are alternatives to each other. Read the [Diagram Collection Guide](Diagram-Collection-Guide.md) for the color legend and viewing options. GitHub, Obsidian and the [Mermaid Live Editor](https://mermaid.live/) all render these files.

Several diagrams overlap and some still group functions under the retired Dynamic Arrays and Excel-specific labels; each of those diagrams says where its functions live now. Function pages are the source of truth for categories, syntax and platform support.
