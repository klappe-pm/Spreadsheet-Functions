# MINUS

## Description

**MINUS** subtracts its second argument from its first and returns the difference. `=MINUS(C2, B2)` returns the same number as `=C2-B2`. The function is the named form of the subtraction operator, which makes it useful when a formula is generated by a script or when a reviewer prefers a named function.

Use MINUS for variances, balance changes and movement counts, where the order of the two values matters. The first argument is the number you start with, and the second is the number you subtract. Swapping the arguments reverses the sign of the result.

MINUS handles two numbers at a time. To subtract one total from another, sum each range first and pass the totals in. Microsoft Excel has no MINUS function, so Excel users write the `-` operator instead.

## Syntax

```excel
=MINUS(value1, value2)
```

### Parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `value1` | Yes | The minuend, the number you start with. |
| `value2` | Yes | The subtrahend, the number that is subtracted from `value1`. |

### Return Value

A number equal to `value1` minus `value2`. A negative result appears when `value2` is larger. If either argument is text that cannot be read as a number, the formula returns an error.

## Examples

All examples use this planned and actual cost list.

| Cost Item | Planned | Actual |
| --- | --- | --- |
| Rent | 1200 | 1250 |
| Freight | 800 | 760 |
| Staff | 5400 | 5400 |

### Example 1: Overspend on Rent

```excel
=MINUS(C2, B2)
```

**Result:** `50`

Actual rent of 1250 minus planned rent of 1200 gives an overspend of 50.

### Example 2: Underspend on Freight

```excel
=MINUS(C3, B3)
```

**Result:** `-40`

Freight came in 40 below plan, so the variance is negative.

<!-- Image 2: Cost Variance Results. See Images/Google-specific/MINUS.md -->

### Example 3: Two Literal Numbers

```excel
=MINUS(3, 4)
```

**Result:** `-1`

The second number is larger, so the difference is negative.

### Example 4: No Variance

```excel
=MINUS(B4, C4)
```

**Result:** `0`

Staff costs matched the plan, so the difference is zero.

### Example 5: Subtract Totals

```excel
=MINUS(SUM(C2:C4), SUM(B2:B4))
```

**Result:** `10`

The actual total is 7410 and the planned total is 7400, so the overall variance is 10.

## Story Problems

### Problem 1: Stock Sold During the Week

A shop records opening and closing stock for each product. The data is in `A1:C4`.

| Product | Opening Units | Closing Units |
| --- | --- | --- |
| Mug | 120 | 95 |
| Tote | 60 | 60 |
| Pen | 300 | 240 |

**Task:** In column D, calculate the units sold for each product, which is opening stock minus closing stock.

**Solution:**

```excel
=MINUS(B2, C2)
```

Fill the formula down to D4.

**Answer:** `25`, `0` and `60` for Mug, Tote and Pen. Mugs and pens left the shop, and no totes sold that week.

### Problem 2: Mileage Claims

A driver logs the odometer reading at the start and end of each trip. The readings are in columns B and C of `A1:D3`.

| Trip | Start Reading | End Reading |
| --- | --- | --- |
| Site visit | 15230 | 15612 |
| Client drop-off | 15612 | 15698 |

**Task:** In column D, calculate the kilometers driven on each trip.

**Solution:**

```excel
=MINUS(C2, B2)
```

Fill the formula down to D3.

**Answer:** `382` and `86` kilometers. The site visit covered 382 kilometers and the drop-off covered 86.

## Use Cases

### Budget Variance Reporting

**Scenario:** A department manager compares actual spend with the approved plan each month and reports the gap.

```excel
=MINUS(C2, B2)
```

**Why It Works:** A positive variance means the department spent more than planned. Keeping actual in the first argument makes overspend positive and underspend negative, which matches most finance reports.

### Stock Movement Tracking

**Scenario:** An inventory clerk needs the units removed from stock between two counts.

```excel
=MINUS(B2, C2)
```

**Why It Works:** Opening stock minus closing stock gives the units removed. A negative result would signal stock added between counts.

## Common Errors

| Error | Cause | Fix |
| --- | --- | --- |
| Error in place of a number | One argument is text, such as a number with a currency symbol. | Clean the text, or convert it with VALUE. |
| Sign is reversed | The arguments were entered in the wrong order. | Put the starting value first. |
| Formula does not calculate | The function has fewer or more than two arguments. | Provide exactly two values. |

## Platform Differences

| Platform | Availability | Notes |
| --- | --- | --- |
| Microsoft Excel | Not available | Use the `-` operator, for example `=C2-B2`. |
| Google Sheets | Available | Returns the same result as the `-` operator. |

## Tips and Best Practices

- Put the starting or baseline value first so a positive result means growth or overspend.
- Use the `-` operator in shared workbooks where most readers expect it, and MINUS where a named function is clearer.
- Sum ranges first and then subtract the totals, as in Example 5.
- Check for text values before subtracting, because a single text entry can break a total.
